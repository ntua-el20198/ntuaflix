To achieve the dynamic navigation based on the user's role (admin or simple user), you can use Jinja2 templating in your HTML files. In your homepage.html and navigation.html, you can check the value of the is_admin session variable and conditionally render the navigation accordingly.

Here's an example modification for your homepage.html:

html
Copy code
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- ... your other head elements ... -->
</head>
<body>
    <!-- Include the navigation template -->
    {% include 'navigation.html' %}
    
    <!-- Your homepage content goes here -->
    <h1>Welcome to NTUAflix!</h1>
    
    <!-- Other content... -->
</body>
</html>
And for your navigation.html:

html
Copy code
<nav> 
    <img src="{{ url_for('static', filename='images/logo.png') }}" alt="Logo" class="logo">
    <!-- Conditionally render admin-specific links -->
    {% if session['is_admin'] == 1 %}
        <a href="{{ url_for('admin_dashboard') }}">Admin Dashboard</a>
    {% endif %}
    <!-- Common links for both admin and simple user -->
    <a href="{{ url_for('movies') }}">Movies</a>
    <a href="{{ url_for('tv_shows') }}">TV Shows</a>
    <!-- Add more links as needed... -->
</nav>
In this example, I assumed you have different routes for admin-specific pages like 'admin_dashboard', 'movies', 'tv_shows', etc. Make sure to update these route names according to your actual routes.

This way, the navigation will be dynamically generated based on the user's role. The admin-specific links will only be displayed if the user is an admin. Adjust the code according to your specific routes and navigation structure.
