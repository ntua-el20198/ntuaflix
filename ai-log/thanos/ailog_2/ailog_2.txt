2. Μία εφαρμογή CLI (Command Line Interface) για τις παραπάνω λειτουργίες, η οποία θα
λειτουργεί ως client του REST API που παρέχεται από το back-end υποσύστημα,
προσφέροντας στο χρήστη της τη δυνατότητα να εκτελεί λειτουργίες μέσω ενός shell. 

Η εφαρμογή Command Line Interface (CLI) είναι ένα πρόγραμμα που επιτρέπει στον χρήστη να επικοινωνεί με ένα σύστημα μέσω ενός κέλυφους (shell) ή ενός περιβάλλοντος εντολών. Για το προαναφερθέν πρότζεκτ του μαθήματος "Σχεδιασμός Λογισμικού," η εφαρμογή CLI θα λειτουργεί ως client που θα αλληλεπιδρά με το back-end υποσύστημα μέσω του παρεχόμενου REST API. Αυτό σημαίνει ότι ο χρήστης θα μπορεί να εκτελεί λειτουργίες σχετικές με ταινίες μέσω του κέλυφους.

Παραδείγματα ενδεικτικών λειτουργιών που μπορεί να προσφέρει η εφαρμογή CLI για το συγκεκριμένο πρότζεκτ:

Εμφάνιση λίστας ταινιών: Ο χρήστης μπορεί να εκτελέσει μια εντολή που θα ανακτά τη λίστα με διαθέσιμες ταινίες από το back-end.

Αναζήτηση ταινιών: Ο χρήστης μπορεί να εκτελέσει εντολή αναζήτησης για ταινίες με βάση διάφορα κριτήρια.

Προβολή λεπτομερειών ταινίας: Ο χρήστης μπορεί να ζητήσει περισσότερες πληροφορίες για μια συγκεκριμένη ταινία.

Αποθήκευση ταινίας: Ο χρήστης μπορεί να αποθηκεύσει μια ταινία στη δική του λίστα ή να προσθέσει σχόλια.

Συντομεύσεις και βοήθεια: Η εφαρμογή CLI θα πρέπει επίσης να παρέχει συντομεύσεις και βοήθεια για να καθοδηγεί τον χρήστη στη χρήση της.

Ο χρήστης θα μπορεί να επικοινωνεί με το back-end υποσύστημα μέσω των διαθέσιμων λειτουργιών που παρέχονται από το REST API, και η εφαρμογή CLI θα είναι εκείνη που θα διαχειρίζεται αυτήν την επικοινωνία για λογαριασμό του χρήστη.
